# Vidéos V4 : Pack 5 Aura Bio

Toutes les vidéos sont dans `videos/`, avec les noms `AURA4_<n°>_<concept>_<format>_<durée>.mp4`.

Elles ont toutes la même base :
- **Structure** : hook dans la première seconde, puis offre, puis écran de fin (prix 49, 110 barré, « اطلب توّا », pied de page AURA BIO · الخلاص عند الاستلام · 50 500 051).
- **Son** : musique originale et effets sonores synchronisés.
- **Voix off** : aucune. Les vidéos se comprennent sans le son.
- **Zones de sécurité** : en 9:16, tout le texte est entre les 14 % du haut et les 35 % du bas. La partie basse ne contient que le produit.
